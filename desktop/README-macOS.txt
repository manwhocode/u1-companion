U1 Companion — macOS Terminal installer

ENGLISH
1. Extract the ZIP on your Mac. Keep all files together.
2. Read LICENSE and AGREEMENT.en.txt.
3. Double-click U1-Companion.command. It opens Terminal.
4. Enable Root Access / SSH on the U1. Leave it idle with heaters off.
5. Type yes to accept the agreement, enter the printer IP, then select
   1 Install, 2 Update or 3 Uninstall.
6. On the first connection, verify the SSH fingerprint before accepting.
7. Enter the root SSH password. Factory default: snapmaker, unless changed.
   Password characters are hidden; this is normal. The launcher does not save it.
8. Confirm the operation plan and wait for completion. Keep power connected.

If macOS does not allow opening the file, review the system warning and its
Privacy & Security settings. Do not disable system protections globally.
This .command file is for macOS; on Windows download U1-Companion-Setup.exe.
Actual execution on a Mac still needs verification.

РУССКИЙ
1. Распакуйте ZIP на Mac, оставив все файлы в одной папке.
2. Прочитайте LICENSE и AGREEMENT.ru.txt.
3. Дважды нажмите U1-Companion.command — откроется Терминал.
4. Включите Root Access / SSH на принтере. Печать и нагрев должны быть выключены.
5. Введите yes для согласия, IP принтера и номер операции:
   1 — установка, 2 — обновление, 3 — удаление.
6. При первом подключении проверьте отпечаток SSH перед подтверждением.
7. Введите SSH-пароль root: snapmaker, если его не меняли.
   Символы пароля не отображаются — это нормально. Пароль не сохраняется.
8. Подтвердите план и дождитесь завершения. Не отключайте питание.

Если macOS блокирует запуск, прочитайте предупреждение и проверьте настройки
«Конфиденциальность и безопасность». Не отключайте защиту системы целиком.
В Windows используйте U1-Companion-Setup.exe, а не файл .command.
Запуск на реальном Mac пока требует проверки.
