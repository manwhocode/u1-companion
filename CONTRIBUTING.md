# Contributing

Please fork this repository, create a feature branch, and open a Pull Request. Do not request direct write access. Changes are merged only by the project owner after review. New commits invalidate previous approval. Never include printer data, credentials, cookies, access codes, certificates, logs or print files in a PR.

Keep upstream Fluidd attribution and GPL-3.0 licensing. Update all 21 U1 Companion locales when changing UI strings. Describe tests and distinguish mocked checks from tests on a physical printer. Never run motion, heating, firmware restarts or live prints during CI. Do not run untrusted PR code on a printer.
