# U1 Companion

Катушки, печать и обслуживание Snapmaker U1. Неофициальное дополнение на основе Snapmaker Fluidd.

Доступен **полный установщик через SSH, ранняя версия**. Установка и откат проверяются на изолированной имитации Linux. Чистая установка на другом физическом U1 ещё не проверена. Неизвестную прошивку или конфликтующие изменения установщик отклоняет до установки.

## Установка

**Windows:** [скачать универсальный EXE](https://github.com/manwhocode/u1-companion/releases/download/windows-installer-v1.0.0/U1-Companion-Setup.exe). Прочитайте соглашение, поставьте галочку, укажите IP и SSH-пароль принтера. Доступны «Установить», «Обновить» и «Удалить». EXE каждый раз получает актуальный установщик — менять его при выпуске новой версии модуля не нужно.

Программа переносная, Python и SSH-клиент уже внутри. Пароль не сохраняется. EXE пока без цифровой подписи; Windows может показать неизвестного издателя. Проверяйте контрольную сумму и скачивайте только из этого репозитория.

**Командная строка:** способ через SSH ниже остаётся доступным.

Включите SSH/root-доступ на U1, остановите печать и выключите нагрев. Откройте Терминал Windows или macOS и подключитесь, заменив `IP_ПРИНТЕРА` своим адресом:

```sh
ssh root@IP_ПРИНТЕРА
```

Введите SSH-пароль принтера. Затем вставьте **в открытое SSH-подключение** одну команду:

```sh
curl -fL https://raw.githubusercontent.com/manwhocode/u1-companion/main/install.sh -o /userdata/u1-companion-install.sh && sh /userdata/u1-companion-install.sh
```

Подтвердите показанный план один раз. Установщик сам загрузит все компоненты, проверит контрольные суммы, сохранит резервную копию, установит дополнение, перезапустит свободный Klipper и покажет ссылку для браузера. Отдельные приложения на ПК не нужны.

[Подробная инструкция и откат](INSTALL.ru.md) · [English](README.md)

Личные библиотеки после новой установки пустые. Встроен только публичный каталог Snapmaker. Почты, аккаунты, ключи, катушки и история автора в поставку не входят. Alexa, GPT и внешний доступ каждый пользователь подключает сам.

Возможности: мои цвета и катушки, вес пустых катушек и остаток пластика, QR/NFC, учёт расхода и стоимости, печать и паузы, калибровка K, температуры, обслуживание, сушка, вентиляторы крышки, необязательные Alexa и GPT, внешний вход по коду. Интерфейс переведён на 21 язык.

Текущие исходники интерфейса находятся в frontend/, сервисов — в backend/, голосового моста — в alexa/. Настоящих ключей, кодов входа, данных катушек, сертификатов, моделей печати, журналов и резервных копий в репозитории нет. Исторические установщики в tools/legacy/ не устанавливают весь текущий функционал.

Изменения предлагайте через Pull Request из своей копии. Право записи в этот репозиторий и решение о слиянии остаются у владельца. Лицензия GPL-3.0 сохраняется: она разрешает людям изменять и распространять их собственные копии. Подробности сборки и ограничений — в README.md.
