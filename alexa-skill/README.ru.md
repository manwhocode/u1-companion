# Личный голосовой навык U1 Companion

Навык принимает команды; уже существующий мост Alexa озвучивает уведомления. Это независимые подключения. API-ключ GPT не требуется. Код обрабатывается в вашем Alexa-hosted навыке Amazon; отдельный Home Assistant или сервер автора не используются.

## Подключение

1. Обновите Companion до alpha.14 или новее. Включите внешний доступ и проверьте свою HTTPS-ссылку. Принтер использует исходящий туннель; порт Moonraker не нужно открывать в роутере.
2. Откройте https://developer.amazon.com/alexa/console/ask и войдите тем же Amazon-аккаунтом, которому принадлежит Echo. Если требуется регистрация разработчика, прочитайте и примите условия самостоятельно.
3. Создайте Custom skill с размещением Alexa-hosted (Python). Выберите German (DE) или English (US). Публичная публикация не нужна для личного теста. Возможности и квоты размещения определяет Amazon: проверьте их в своём аккаунте.
4. Скопируйте Skill ID. В Companion → настройки → Alexa → «Голосовое управление Alexa» вставьте ID и внешний адрес с окончанием `/u1-alexa/skill`. Например `https://YOUR-TUNNEL.trycloudflare.com/u1-alexa/skill`.
5. Нажмите «Подготовить подключение» и «Скачать настройки навыка». Это **личный config.json с секретом**, не добавляйте его в публичный GitHub, переписку или библиотечный экспорт. Повторная подготовка меняет ключ и отключает прежнюю привязку.
6. В Amazon Code замените `lambda_function.py` файлом из `lambda/` и добавьте скачанный личный `config.json` рядом. Обработчик: `lambda_function.lambda_handler`. Дополнительных библиотек нет. Сохраните и выполните Deploy. Пустой config.json в публичном ZIP — только шаблон.
7. В Build → Interaction Model → JSON Editor вставьте `models/de-DE.json` или `models/en-US.json`. Сохраните и выполните Build Model. В Test включите Development. Echo должен принадлежать этому же аккаунту и использовать язык модели.
8. В Companion включите голосовое управление и получите шестизначный код. За пять минут произнесите «Alexa, öffne Druck Helfer», затем «Drucker verbinden mit [код]». Для английского: «Alexa, open Printer Helper», затем «link printer with code [code]».
9. После голосового подтверждения привязки проверьте сначала статус и оставшееся время. Проверку движения и запуска выполняйте только находясь у принтера с отдельной тестовой моделью.

Если внешний адрес изменился, поправьте `url` в личном config.json навыка и снова выполните Deploy. Ключ и Skill ID не меняются. Не публикуйте личный config.json. Для отключения снимите переключатель в Companion или выключите внешний доступ. Перед обновлением или удалением модуля выключите голосовое управление и внешний доступ.

## Команды и варианты фраз

Полный список немецких и английских вариантов находится в `models/`. Русские названия ниже описывают действия в Companion; русской языковой модели в этом пакете нет.

| Действие | Немецкий пример | Английский пример |
|---|---|---|
| Состояние и процент | Druckerstatus | printer status |
| Оставшееся время (оценка по прогрессу) | wie lange noch | time remaining |
| Продолжение | Druck fortsetzen | resume the print |
| Повтор последней печати | letzten Druck wiederholen | repeat the last print |
| Отмена печати | Druck abbrechen | cancel the print |
| Пауза | Druck pausieren | pause the print |
| Пауза с опусканием | pausiere für Magnete | pause for magnets |
| Таймер паузы | pausiere für zehn Minuten | pause for ten minutes |
| Отмена таймера | automatisches Fortsetzen abbrechen | cancel automatic resume |
| Избранная модель | drucke den Favoriten [название] | print favorite [name] |
| Ночной режим, только вентиляторы крышки | Nachtmodus einschalten | enable night mode |
| Вернуть штатное управление вентиляторами | Nachtmodus ausschalten | disable night mode |
| Ошибки | warum hat der Drucker angehalten | why did the printer stop |
| Обслуживание и калибровка стола | wann ist die Wartung fällig | when is maintenance due |

После открытия навыка команды можно произносить напрямую. После вопроса ответьте Ja / Yes или Nein / No. Общая команда Alexa Stop закрывает диалог; для отмены печати используйте явную фразу Druck abbrechen / cancel the print.

## Поведение

- Голосовое управление выключено по умолчанию. Оно не зависит от переключателя уведомлений Alexa.
- Проверяются HMAC, ID навыка, привязанный аккаунт, свежесть запроса и повторные request ID. Подтверждение привязано к сессии и истекает через минуту. Повторное подтверждение не отправляет команду заново.
- Запуск, повтор, продолжение, отмена и пауза с опусканием запрашивают голосовое подтверждение. Проверки Companion повторно проверяют задание, файл, катушки, координаты и блокирующие ошибки.
- Повтор и запуск избранного используют стандартное соответствие T1–T4 → головки 1–4, выравнивание стола включено. Alexa называет файл перед подтверждением. Не подтверждайте, если нужна другая схема катушек; подготовьте запуск в интерфейсе.
- Ночной режим действует только на вентиляторы крышки; штатная защита температуры имеет приоритет. «Выключить ночной режим» возвращает штатную автоматику, а не принудительную максимальную скорость.
- Отмена печати отличается от паузы. Голосовая аварийная остановка не добавлена: она не подменяет кнопку аварийной остановки.
- Если ответ не получен вовремя, команда не повторяется автоматически. Проверьте физический принтер и интерфейс, прежде чем давать новую команду. Голосовое «запрос отправлен» не означает, что движение уже завершилось.
- Привязывается аккаунт Amazon, а не биометрический голос человека. Команды могут произносить другие люди возле устройств этого аккаунта.

Реальная проверка с Echo и настройка навыка в Amazon ещё необходимы. Автоматические тесты не доказывают распознавание речи на физической колонке.
