# Security

Do not post credentials, pairing codes, cookies, certificates, personal printer information or full device logs in public issues. Report vulnerabilities privately to the owner using GitHub private vulnerability reporting when available. Do not publish exploit details before coordination.

Keep Moonraker and Klipper off the public internet. The optional temporary external tunnel must terminate at the authenticated loopback gateway, never directly at Moonraker. The pairing code grants printer-management access: keep it private and rotate it if disclosed. Protect physical printer access and local network access.
